# DriveBaseAPI for CKKWRO2026
A framework for Pybricks MicroPython on LEGO® SPIKE™ Prime.
Inspired by the block-based scripting of LEGO® MINDSTORMS® EV3 Education, with logic and algorithms adapted from github/AomIsReal

Features
- Sequential, Parallel task execution.
- Asynchronous behavior without requiring concept of asynchronous programming.
